__Pray Latin__ is an application helping with praying in Latin and learning Latin prayers.
<p>
It displays prayers in your own language inline to help understand the Latin text which in
turn allows to quickly learn prayer in Latin.
<p>
__It contains large collection of prayers__ in Latin and other languages and it can be used
as daily prayer book.
