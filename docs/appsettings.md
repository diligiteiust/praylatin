# App settings description

<img src="../assets/settings.png" alt="English List" width="200"/>

The `Pray Latin` app is designed to be very simple and useful without a need to adjust
any settings. Default configuration is prepared for most typical usage.

However, there are a few options that you might want to adjust for your personal
preferences. Here is a description of what the configuration option mean.

## UI Language

The option allows to change the app interface language.

## Prayer Language

The option allows to set the prayer language, that is the first/main language for the
displayed prayers.

Even though, the intention for the app is to display and learn Latin prayers, it is possible
to set a different language as the main prayer language.

## Second Language

The second prayer language is the in-line translation of the prayer text. It can be set to
any available language or it can be turned off.

If the prayer does not have version in the selected second language, the app will display only
prayer in the main language.

If some prayers are available only in the second language, the app with also include
these prayers in the prayers list.

## Prefer Translation

Prayers in different languages usually differ, sometimes very significantly. Therefore when
the second language is displayed inline, it does not always provides accurate translation for
the first language prayer.

Therefore, there is an option to display more direct translation of the Latin prayer in the
selected second language. That is, if the translation is available. If the option is set to `On`
and direct translation is not available, the app automatically displays the original prayer text
in the second language.

## Grouping

This allows you to switch between long list of all prayers and grouped prayers. Grouped prayers
might be easier to navigate when searching for a specific prayers category.

Long flat list displays prayers in alphabetic order.
